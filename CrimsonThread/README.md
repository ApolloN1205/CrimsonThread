# CrimsonThread

A one-page portfolio for Norbert Adamiak. Open index.html to see the portfolio. Open studio.html to edit a draft. The starter includes the approved introduction, empty sections and blank contact details.

## Put it on GitHub Pages

1. Extract the ZIP. Create a public repository named crimsonthread.
2. Upload the extracted files to the root of main, so index.html is beside README.md.
3. In Settings → Pages, select Deploy from a branch, main and /(root), then Save.
4. Open the website address shown in Settings → Pages. Share that address on LinkedIn.

## Add your first entry

Open studio.html, select Projects, and click + Add entry. Enter a title and description. For a side-by-side card, choose Image left and add a picture. Preview draft shows the page, and Return to editor takes you back. Contact & profiles holds social links, business email and an optional public phone number. Empty sections stay hidden.

## Publish an edit

Choose Export content.js, replace the original content.js with the downloaded file, and commit it to main. You can also edit content.js directly in GitHub. The public studio creates drafts and downloads. Only a repository writer can publish. Keep private information and unredacted credentials out of files you commit.
